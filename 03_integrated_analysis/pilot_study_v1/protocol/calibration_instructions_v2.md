# 四例规范试用怎么填

这是开发案例上的规范试用，不是正式评价。案例以前已经被讨论过。请先只打开 phase_a。

1. 阅读该案例给出的标题、摘要和中性问题。
2. 在空表里分开填写内容角色、拆分、实体身份、测量形式、原文支持和比较范围。没有模型引用时，引用支持先留空，不要把原文支持写成信息不足。
3. 可以写无法判断，也可以写规范里不清楚的地方。
4. 保存并锁定 A。锁定之前不要打开 phase_b。
5. 锁定之后才阅读 phase_b 里标明 historical_model_output / non_gold 的历史输出，再填引用支持和差异。
6. 把规范需要修改的地方单独记下来。这些标签以后不并入独立正式评价。

本包没有指定评阅者，也没有替任何人填写科学答案。phase_a 的 workflow_status 为 pending，表示还没有人提交。
