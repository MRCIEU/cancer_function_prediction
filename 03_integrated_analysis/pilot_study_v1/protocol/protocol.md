# 证据档案协议 evidence_dossier_protocol_v1

本文件是拟用于下一阶段的研究协议。它表示合同和评价方案已经保存。它不表示正式实验已经执行，不表示协议已经外部预注册，也不表示科学结论已经得到验证。计数以本 child 的 `tables/evidence_to_design.parquet` 为准。新的提取和比较模板状态是 `untested_protocol_v1`。

## 1. 面向谁，输入和输出是什么

正式任务面向生物医学研究者，以及支持文献分析的信息人员。主要使用对象不是临床治疗决策者。本项目目前以研究者梳理证据为目标。没有用户研究，因此不写阅读效率或决策改善；潜在用途只作为尚未测量的用途。

输入是一个 gene–cancer pair，以及一份明确冻结的文献集合。默认范围继承 `id_alignment_v2` 下从 CORE 出发、与 SemMedDB 共享的 pair。`accepted` 表示满足映射规则，不是逐条人工核对正确。范围 E 不是全部 SemMedDB 癌症关系。档案必须写明使用的是哪一批冻结记录和摘要。两库的联合集合不是该 pair 的全部文献。

输出是一份可追溯的证据比较档案：摘要中的结构化发现、跨文章比较，以及这些比较所依据的原文位置。三层能力分开记录，不压成一个质量总分，也不默认等距等级。

## 2. 三个研究问题

RQ1。在摘要范围内，能否忠实组织与目标 pair 有关的本文发现，并保留决定含义的实体角色、比较对象、结局和条件。

- 输入：冻结摘要的标题和正文，以及 pair 的基因名、疾病名和需要区分的别名。
- 方法：沿用已成功的主模型和运行框架，按 `finding.protocol_v1` 做结构化提取。程序负责单位、版本和引用定位。
- 评价单位：finding。一句可以对应多条 finding。
- 分析：已输出 finding 的原文支持；只有预先独立列出目标结果的少数摘要才计算遗漏。
- 可支持的结论：这些摘要里，输出是否保住了角色、问题和条件。不能外推到未读文献，也不能在没有独立清单时报告 recall。

RQ2。这些结构化发现能否支持合理的跨文章比较，明确哪些关系可以描述、哪些方向可以对照、哪些数值可以直接比较，以及不能判断的具体原因。

- 输入：两篇完整摘要、一个中性问题，以及待核对的候选 finding。
- 方法：按 `comparison.protocol_v1` 比较。finding 与原文冲突时记录冲突，不静默改写。
- 评价单位：文章对加中性问题组成的案例。案例内的多个 finding 不是多项独立研究。
- 分析：描述、方向、数值三层分开；无法判断保留为独立状态。
- 可支持的结论：在给定摘要和问题下，比较层次是否合理。不能把表面方向不同写成科学矛盾，也不能把方向相同写成测量相同。

RQ3。在给定冻结文献集合内，联合 CORE 和 SemMedDB 增加了哪些可形成的比较与研究条件。其中哪些增量在正式人工评价后仍然成立。

- 输入：该 pair 已冻结的 PMID 与来源连接，以及 RQ2 的案例。
- 方法：先按目标 pair 的 PMID 集合做来源四分类，再在人工核对后的案例上看各类有没有合理的比较依据。
- 评价单位：比较案例、文章对和 pair 分开计数。
- 分析：文章增量、比较机会和经核对的比较是三种量。
- 可支持的结论：材料层面的互补，以及核对之后仍然成立的比较。同一套判断不能证明单库模型更差。没有对照运行就不写模型提升。

## 3. 方法路线

冻结 pair 与语料，保留两库原始记录及追溯，做摘要提取，组织同问题候选，做有依据的比较，生成档案。

实际科学判断不能由字段为空或标签不同直接替代。历史结论、来源库名称、CORE 角色标签和 SemMedDB predicate 不作为比较正确性的提示。若要检验这些标签能否改善判断，那是独立的 K 类实验，不在本协议的默认路线里。

本轮不引入新模型、encoder、微调或多模型投票。未来运行继承已经成功的主模型配置。新 schema 和 prompt 另存为 `untested_protocol_v1`，不能声称与旧结果等价，也不能声称性能已经改善。

直接数值比较需要相容的结局、比较对象、尺度和时间。合并效应还需要额外的统计假设。不是每一种条件缺失都自动否决比较。

E5 保留为探索性的候选问题细化。E3 和 E6 是设计诊断。K、E4 和开放模型对照不是完成核心研究的默认必要条件。

## 4. 单位

finding、比较案例和字段级证据的定义在 `schemas/finding_protocol_v1.json`、`schemas/comparison_protocol_v1.json` 和 `schemas/field_evidence_v1.json`。这里只记录会改变解释的规则。

一条 finding 对应一个可辨认的实证结果，或单独的一条作者解释。研究对象、暴露或测量、比较对象和结局用来界定它。同一句可以支持多条 finding。表达和生存出现在同一句时允许拆开。

目标基因、实际测量对象及其形式、细胞或组织区室、配体或受体、干预构建体必须分开。别名不同、RNA 与蛋白不同、实体身份不同，是不同对象。TNFRSF9/CD137、TNFSF9/CD137L 和 CD137-Fc 不能因为名称相关就合并。

`discourse_role` 区分本文结果、作者解释、背景和无法判定。作者解释可以进入档案的单独部分，不进入本文实证结果的比较。`other` 是未覆盖的结果类型，保留，不等于作者解释，也不直接删除。

表达或分布的结局是表达、定位或丰度。预后关联里，表达可以是预测变量，结局是生存或其他预后终点。不能因为出现 expression 就把预后结果归成表达问题。

方向必须连着测量对象、比较对象和结局。“肿瘤相对正常表达升高”和“高表达相对低表达生存更差”不能共用一个没有参照物的 increase 或 decrease。

比较案例的 `case_id` 由目标 pair、文章对、中性问题和两侧文本版本组成。finding 对是案例内对象，不靠输出行号获得科学身份。同一文章对可以有多个问题。

`observed_direction_pattern`、测量关系、研究系统或人群、能否描述、能否对照方向、能否比较数值，分开保存。`opposite` 只表示报告方向表面不同。

信息状态分开：已报告、文本中未报告、无法判断、不适用、旧合同未记录、技术失败。旧表缺少的字段是 `not_recorded_in_legacy`，不能改写成摘要里未报告。技术失败也不能改写成无法判断。

每个关键判断有自己的 `evidence_ref`，包含文本版本、PMID、可见范围、原文、位置，以及 `supported_field`。没有字段连接时记 `field_link_unknown`，不凭经验补建。引用能定位，和引用在语义上支持该字段，是两次检查。样本组成句可以支持人群信息，不能因为它不支持方向就判定整条引用无效。对“未报告”只保存检查过的文本范围和字段，不伪造证明不存在的引句。

## 5. 两个知识库进入流程的位置

原生记录保留 `source_record_id`、各自的原始字段、来源句，以及 pair 与 PMID 的连接。CORE 的属性不改写成 SemMedDB 的 predicate。

来源四分类使用该 pair 自己的 PMID 集合。一个 PMID 在别的 pair 或库的其他位置出现，不能改变这个 pair 的分类。四分类描述的是材料能否形成比较，不是单库模型重跑后的表现。

来源句和摘要句只有在字符串或位置关系可核实时才连成同一句。版本不明保持未记录。E3 没有完整的文本版本对应，不能解释成摘要比来源句更准确。

新从摘要得到的 finding 不必有一条直接对应的 KG 关系。判断要能追到 finding、原文和原生记录；追不到 KG 边不是错误。

## 6. 指标和主张

指标定义在本 child 的 `tables/metric_spec.parquet`。没有人工标签时，依赖人工的指标是 `not_evaluated`，不填 0。没有该类案例和数值未知使用不同状态。

正式评价使用真实生产流程的输出，保留提取、候选选择、比较和档案之间的对应。E6 的固定摘要直接比较不能代替这条端到端评价。E6 只保留为两次提取的结构变化和四案字段转移，不计算端到端可靠性、科学准确率，也不计算 ERASER 论文定义的 sufficiency 或 comprehensiveness 概率。

## 7. 贡献边界

主贡献是三件同时成立的东西：一套有单位和追溯、并且经过核对的研究者证据档案；对研究问题、条件和比较边界的实证描述；对双库在材料层面和经核对比较层面的互补性分析。

自动化是实现手段。参考标注和软件是附属产物。不预先声称新的 SOTA、普遍更高的准确率、新的生物机制、已经确认的研究空白或临床改善。E5 的三候选是问题细化过程，不是已经确认的空白。

## 8. 和旧结果的关系

旧输出按 `tables/legacy_projection.parquet` 投影。投影保留旧值、来源键和转换规则。语义不能确定的字段留空。程序不通过模板或正则把旧文本解读成新的已验证发现。历史模型标签原样保存，并标为非 gold。

本协议相对旧方案的取舍是：比较可以同时看到摘要和候选 finding，但 finding 只是待核对输入；来源标签不进入正确性提示；表达和预后按结局而不是按单词归类；方向和测量分开；证据落到字段而不是档案末尾的一组通用引用。
